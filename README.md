# DONGSELL

직셀의 셀러 관리 화면을 참고한 로컬 화면 미리보기입니다. 실제 서비스 연동보다 화면·메뉴·팝업 구현을 먼저 진행한 버전입니다.

## 실행

`start.bat`을 실행하고 http://127.0.0.1:3000 을 엽니다. 처음 실행 시 필요한 패키지를 준비합니다. 실행 창을 닫으면 서버가 종료됩니다.

- 브랜드: DONGSELL
- 홈: 대시보드
- 메뉴: 상품수집, 상품 관리, 주문/CS, 마켓, 판매정보, 단어관리, 카테고리분석, 알림, PC 연결, 요금제, 내 정보
- 새 수집그룹·단어관리 화면은 로컬 초안이며 외부로 수집/전송하지 않습니다.
- 기존 실제 수집기 화면은 /collector 에 보존되어 있습니다.
- 화면 구현 범위와 미검증 부분: UI_STATUS.md

## 저장

상품 DB: data/collector.db
상품 이미지: data/images
새 UI 수집그룹·단어 목록: 브라우저 로컬 저장소(dongsell.ui.*.v1)
마진·상품 검수/메모: 로컬 DB workspace_state

## 소스 변경 후

frontend 폴더에서 빌드를 갱신한 다음 start.bat을 실행하세요. 현재 제공된 빌드는 이번 화면 변경을 포함합니다.
